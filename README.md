# HabitFlow — трекер привычек

Приложение для формирования полезных привычек. Пользователь создаёт привычки,
отмечает их выполнение одним касанием, накапливает серию дней (streak) и
отслеживает прогресс за неделю.

## Технологии

- **React 18 + TypeScript + Vite**
- **React Router** (роутинг: главная / статистика)
- **Vitest + React Testing Library** (автотесты)
- **CSS** (адаптивная вёрстка через media queries)

## Основные функции

1. **Создание и список привычек** — название, цвет, дни недели.
2. **Ежедневная отметка + серия дней (streak)** — одно касание, авто-подсчёт.
3. **Статистика за 7 дней** — прогресс выполнения по дням недели.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:5173

## Тесты

```bash
npm test
```

Запускается 7 автотестов (позитивные и негативные сценарии).

## Сборка

```bash
npm run build
```

## Структура проекта

```
src/
├── main.tsx               # точка входа
├── App.tsx                # роутинг
├── types.ts               # типы (интерфейс Habit)
├── storage.ts             # работа с localStorage + логика streak
├── index.css / App.css    # базовые стили и адаптивность
├── components/
│   ├── HabitCard.tsx      # карточка привычки
│   ├── HabitList.tsx      # список привычек
│   ├── HabitForm.tsx      # форма создания (с валидацией)
│   └── ProgressBar.tsx    # прогресс-бар дня
├── pages/
│   ├── HomePage.tsx       # главный экран
│   └── StatsPage.tsx      # статистика за 7 дней
└── __tests__/
    └── habit.test.tsx     # автотесты (7 шт.)
```

## Хранение данных

Данные хранятся локально в `localStorage` (ключ `habitflow.habits`).
Приложение работает офлайн — отметка привычек не требует сети.
